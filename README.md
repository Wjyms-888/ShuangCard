# 爽Card · ShuangCard 🃏

**把你的照片，做成会发光的 3D 全息卡牌。**

爽Card 是一个纯前端的 DIY 网页工具：上传你的图片素材，分层合成、转动视角、镀上材质流光，最后导出一张可以收藏与再编辑的 3D 全息卡片。所有操作都在浏览器里完成——**不上传服务器、不注册账号、零隐私顾虑**。

## 🎉 在线体验（GitHub Pages）

> **<https://Wjyms-888.github.io/ShuangCard/>**

打开即是「创作台」。桌面端浏览器体验最佳（拖拽转卡、滚轮缩放）。

## ✨ 它能做什么

| 能力             | 说明                                             |
| -------------- | ---------------------------------------------- |
| **五层合成**       | 文字 / 特效 ×2 / 主体 / 背景分层独立编辑，每层可调位置、缩放、旋转、景深     |
| **3D 视差**      | 拖拽转动卡片，各层以不同景深位移，呈现立体纵深感；支持普通 / 浮雕双模式          |
| **七种材质**       | 原画 / 镀银 / 烫金 / 古铜 / 虹息（彩虹光栅）/ 磨砂 / 木纹——随视角流转光泽 |
| **层镀材质**       | 每层素材可单独"镀"上材质（比如只有人物流金、背景保持哑光）                 |
| **.holo 卡片文件** | 一键导出/导入：所有图层与配置打进一个文件，发给朋友即可继续编辑               |
| **线稿描边**       | 随主体层自动派生发光描边，强度可调                              |

## 🚀 快速上手

1. 打开创作台，右侧抽屉逐层上传素材（主体 / 背景 / 特效）
2. 在「文字」页签填写卡名、英文卡名、卡述、编号
3. 底部画轨选择卡面材质，拖动卡片欣赏流光效果
4. 满意后点右上角「**导出卡片**」，得到 `卡名.holo` 文件

**和朋友互玩**：把 `.holo` 文件发给他们，对方「导入卡片」即可打开你的卡继续修改——传卡即传作。

## 💻 本地运行

无需构建，任意静态服务器即可：

```bash
# clone 后进入 deploy 目录，任选一种方式：
npx serve .
# 或
python -m http.server 8000
```

## 📁 仓库结构（本目录为可部署的完整站点）


## 🔒 隐私

纯静态站点，无后端、无统计、无 Cookie。你的素材与草稿只存在于你自己的浏览器（localStorage）里。
